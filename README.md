# 🎱 핀볼 공뽑기 (Dopamine Pinball)

친구를 초대해서 함께 즐기는 **멀티플레이어 물리엔진 뽑기 레이스** 게임입니다.
각자 공 하나를 배정받고, 세로로 긴 핀볼 보드(600×4800)를 따라 공이 떨어지며 먼저 골인하는 순서로 순위가 정해집니다.
화면은 선두(골인에 가장 가까운) 공을 따라 내려가고, **우측 상단 미니맵**으로 전체 맵과 모든 공의 위치를 한눈에 볼 수 있습니다.
게임 시작 시 **랜덤 아이템 2개**를 받아 상대를 방해하거나 내 공을 가속할 수 있습니다.

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

1. 닉네임 입력, **우승 조건 선택**(🥇 먼저 골인 / 🐢 늦게 골인) 후 **방 만들기**
2. **초대 링크 복사** 버튼으로 친구에게 링크 전달 (또는 6자리 초대 코드 공유) — 홈 화면의 **🔥 지금 열린 방** 목록에서도 바로 입장할 수 있어요
3. 방장이 **맵 선택** (기본 맵 또는 유저 제작 맵) — 맵 제작·구경은 홈 화면의 **🗺 맵 갤러리**에서. 우승 조건도 대기실에서 변경 가능
4. 친구가 모이면 방장이 **게임 시작**
5. 셔플을 지켜보다 방장이 낙하 버튼을 누르면 공이 떨어집니다. 아이템을 써서 우승하세요!

### 🔥 공개 방 목록 & 👁 관전

- 홈 화면에 **현재 열린 모든 방**이 보입니다 (방장·맵·인원·게임중 여부, 5초마다 자동 갱신)
- 대기 중인 방은 **입장**, 어느 방이든 **👁 관전** 가능 — 게임이 한창이어도 중간부터 볼 수 있습니다
- 관전자는 공·아이템 없이 경기만 지켜보며, 인원 제한(10명)에 포함되지 않습니다
- 관전 인원은 대기실과 방 목록에 👁 숫자로 표시됩니다

### 게임 모드

| 모드 | 인원 | 특징 |
|------|------|------|
| 🎮 아이템전 (방 만들기) | 최대 **10명** | 실시간 접속, 각자 아이템 2개를 직접 사용 |
| 🎲 올랜덤 (대기실 버튼) | 최대 10명 | 맵·인당 공 개수·우승 조건·낙하 타이밍·아이템 발동까지 **전부 시스템이 결정** — 전원 관전, 순수 운의 승부 |
| 🎪 이벤트 추첨 | 참가 최대 **500명** + 시청 무제한 | 이름만 등록, 아이템 자동 발동, 녹화된 낙하를 전원이 동시 시청 |

**이벤트 추첨 모드 동작 방식**
1. 홈 화면 → **🎪 이벤트 추첨 만들기** → 초대 링크(`?event=코드`) 공유
2. 링크를 연 사람은 시청자가 되고, 이름을 등록하면 공 1개를 배정받음 (최대 500명)
3. 호스트가 **추첨 시작** → 서버가 낙하 전체를 오프라인으로 시뮬레이션해 녹화 (500명 경기도 수십 초 내)
4. 녹화가 끝나면 전원에게 리플레이가 배포되고, **같은 시각에 동기화 재생** — 수천 명이 봐도 서버는 리플레이 파일(gzip)을 한 번씩만 전송하면 되므로 실시간 중계 대비 대역폭이 수십 배 절약됩니다
5. 아이템은 무작위 시점에 무작위 공에게 자동 발동 (충격파·얼리기·돌풍 등), 폭탄 등 맵 구성요소도 그대로 동작
6. 종료 후 호스트는 **새 추첨 준비**로 같은 참가자와 재추첨 가능

참고: 이벤트 추첨 결과는 공정성을 위해 📊 전체 순위(리더보드)에 집계되지 않습니다.

### 방 옵션 (방 만들 때 + 대기실에서 방장이 변경)

- **우승 조건**
  - **🥇 먼저 골인 우승** (기본): 먼저 도착한 순서대로 순위. 미도착 공은 골인 지점에 가까운 순
  - **🐢 늦게 골인 우승**: 늦게 도착할수록 높은 순위. 아이템의 의미가 뒤집힙니다 — 상대를 얼리면 오히려 도와주는 셈이고, 로켓 부스트는 자폭이 됩니다!
- **⚪ 인당 공 개수** (1~5개): 각자 공을 여러 개 배정. 최종 순위는 각 플레이어의 **가장 좋은 공** 기준 (먼저 골인 모드 = 가장 빠른 공 / 늦게 골인 모드 = 가장 늦은 공). 아이템은 내 **선두 공**에 적용됩니다

### ⏩ 게임 중 배속 (방장 전용)

낙하가 시작된 뒤 방장이 화면 오른쪽의 **1× / 2× / 3×** 버튼으로 언제든 배속을 바꿀 수 있습니다.
기본 배속(`server/config.js`의 `TIME_SCALE`)에 곱해지는 값이라, 기본 5에서 3×를 누르면 15배속이 됩니다.
전원(관전자 포함)의 화면에 즉시 반영됩니다.

### 🎁 아이템 소개 → 시작 셔플

게임을 시작하면 바로 떨어지지 않습니다.

1. **아이템 소개** (기본 6초 — `server/config.js`의 `ITEM_INTRO_MS`, `0`이면 건너뜀): 각자 이번 판에 부여받은 아이템이 카드로 한 장씩 공개됩니다. 소개가 진행되는 동안 공은 제자리에 고정되고 낙하도 잠겨 있습니다 (올랜덤 모드에서는 소개 없이 바로 진행).
2. **시작 셔플**: 소개가 끝나면 그때부터 공들이 시작 구역에서 **배치 패턴(일렬·지그재그·타원·V자·X자·산개)** 사이를 계속 옮겨다니고, 전원이 그걸 지켜보다가 **방장이 "🎲 지금 떨어뜨리기!"를 누르는 순간의 위치에서** 낙하가 시작됩니다 (소개 종료 후 5초 내 미입력 시 자동 낙하 — `server/config.js`의 `SHUFFLE_AUTO_DROP_MS`). 새 배치 패턴은 `server/game.js`의 `SPAWN_PATTERNS`에 함수 하나만 추가하면 됩니다.

## 아키텍처

| 구성 | 선택 | 이유 |
|------|------|------|
| 물리엔진 | [Matter.js](https://brm.io/matter-js/) | 웹 물리엔진 중 가장 가볍고(min+gzip ≈ 80KB) 서버/브라우저 양쪽에서 동작 |
| 실시간 통신 | Socket.IO | 방(room) 개념 내장, 재연결 처리 자동 |
| 동기화 | **서버 권위(server-authoritative)** | 물리 시뮬레이션은 서버에서만 실행(60Hz), 클라이언트는 좌표 스냅샷(30Hz)을 받아 보간 렌더링만 수행 |

서버 권위 방식을 쓰는 이유:
- 참가자 전원이 **완전히 동일한 결과**를 봅니다 (물리엔진은 기기마다 미세하게 달라질 수 있음 → 뽑기 게임에서 치명적)
- 클라이언트는 물리 연산을 하지 않아 **저사양 기기/모바일에서도 가볍게** 동작
- 아이템 효과(상대 공 멈추기 등)를 서버에서 검증하므로 치팅 방지

```
server/
  index.js       # Express + Socket.IO 부트스트랩
  rooms.js       # 방 생성/초대코드 입장/방장 승계/맵 선택/퇴장 처리
  game.js        # Matter.js 시뮬레이션 루프, 맵 → 보드 생성, 순위 판정
  items.js       # ★ 아이템 레지스트리 (여기에 추가하면 끝)
  maps.js        # 기본 맵 + 유저 맵 저장소 (data/maps.json 영구 저장, 검증)
public/
  components.js  # ★ 맵 구성요소 레지스트리 (서버/클라이언트 공용, 여기에 추가하면 끝)
  index.html     # 홈 / 대기실 / 맵 에디터 / 게임 화면
  client.js      # 캔버스 렌더러(스냅샷 보간), 맵 에디터, 아이템 UI, 소켓 핸들러
  style.css
data/
  maps.json      # 유저 제작 맵 (자동 생성, git 미추적)
```

현재 아이템:

| 아이템 | 등급 | 대상 | 효과 |
|--------|------|------|------|
| 👻 유령 낙하 | ⭐에픽 | 나 | 3초간 핀과 다른 공을 무시하고 그대로 떨어짐 |
| 🧊 얼리기 | ⭐에픽 | 상대 | 상대 공을 3초간 그 자리에 정지 |
| 💥 충격파 | ⭐에픽 | 나 | 내 공 주변에 폭발을 일으켜 근처의 다른 공들을 날려버림 |
| 🧲 자석 | ⭐에픽 | 나 | 3초간 내 공이 골인 지점으로 강하게 끌려감 |
| 🔀 위치 교환 | ⭐에픽 | 상대 | 상대 선두 공과 내 선두 공의 위치·속도를 맞교환 |
| ⚡ 번개 | ⭐에픽 | 나 | 3초간 나를 제외한 모든 공이 감속 |
| 🚀 로켓 부스트 | 일반 | 나 | 공이 아래로 강하게 가속 |
| 🌪️ 돌풍 | 일반 | 상대 | 상대 공을 위로 날려버림 |
| 🎈 풍선 | 일반 | 상대 | 상대 공이 3초간 커지고 잘 튕겨서 제어 불능 |
| 🕳️ 포탈 | 일반 | 상대 | 상대 선두 공을 맵의 22%만큼 위로 되돌려보냄 |

### 👑 레전드: 🎡 인생은 돌고돌아

- **게임당 10% 확률로, 전체 참여자 중 단 한 명에게만** 3번째 슬롯으로 부여됩니다 (없는 판이 더 많음)
- 상대에게 사용하면 그 공에 **몰래 저주**가 걸립니다 — 겉으로는 아무 표시가 없음
- 저주받은 공이 **골인선을 넘는 순간**, 골인 대신 출발점으로 되돌아가 처음부터 다시 시작합니다 (1회성)
- 발동 순간 "🎡 인생은 돌고돌아!" 전체 공지와 함께 화면이 흔들립니다
- 랜덤 풀·올랜덤·이벤트 추첨의 자동 발동에서는 나오지 않습니다

지속 효과 아이템(자석·번개)은 아이템 스키마의 `tick(game, ball)` 훅으로 구현되어 있어, 매 틱 물리 조작이 필요한 새 아이템도 쉽게 추가할 수 있습니다.

### 새 아이템 추가하기

`server/items.js` 의 `ITEMS` 객체에 항목 하나만 추가하면 됩니다.
이름/이모지/설명/대상 선택 UI까지 클라이언트에 자동 반영되므로 **클라이언트 코드 수정이 필요 없습니다.**

```js
// server/items.js
magnet: {
  id: 'magnet',
  name: '자석',
  emoji: '🧲',
  desc: '3초간 내 공이 골인 지점으로 끌려갑니다.',
  target: 'self',        // 'self' = 내 공 | 'opponent' = 대상 선택 UI 표시
  duration: 3000,        // 0이면 즉발형
  apply(game, ball) {
    ball.plugin.magnet = true;   // 지속 효과는 game.js tick에서 활용 가능
  },
  expire(game, ball) {
    ball.plugin.magnet = false;
  },
},
```

- `apply(game, ball)` — 효과 시작. `Matter.Body.setVelocity` 등으로 물리 상태를 조작하거나 `ball.plugin` 에 플래그 저장
- `expire(game, ball)` — `duration` 경과 후 자동 호출되어 효과 해제
- 배정 개수는 `server/game.js` 의 `ITEMS_PER_PLAYER` 상수로 조절

## 맵 시스템

- **기본 맵**: ⭐클래식(핀 격자), ⭐스피너 파크(회전 막대·회전 십자·범퍼)
- **미니맵 아트 맵 6종**: 미니맵으로 보면 그림이고, 실제로는 핀·범퍼·회전체·폭탄으로 이루어진 맵들
  — 🌼 활짝 핀 꽃 · 👾 픽셀 인베이더(폭탄 눈) · 🍄 대왕 버섯 · 💀 해적 해골(뼈다귀 X벽) · 🚀 로켓 발사(회전 불꽃) · ❤️ 하트 폭포.
  `server/maps.js`의 `arcDots/ringDots/lineDots/pixelGrid` 헬퍼로 그리며, 전부 "점선"이라 공이 그림에 갇히지 않습니다.
- **💣 지뢰밭**: 아무것도 없는 맵에 재생성 지뢰 60여 개 — 골인 길목의 문지기 폭탄 3개가 선두를 되받아치고,
  폭탄이 재생성되기 전에 도착한 공만 무사히 골인합니다 (1등이 마지막에 뒤집히는 맵)
- **비선형 맵 2종**: "위에서 아래로"의 문법을 깨는 맵
  — 🌀 웜홀 정거장(좌우 워프 · 지름길 사다리 포탈 · **밟으면 위로 되돌아가는 저주의 뱀 포탈**) ·
  🎢 트램펄린 산맥(경사로를 타고 내려와 **점프 패드로 장벽을 폴짝 넘는** 상승-하강 반복 코스)
- **코스형 맵 2종**: 직선 낙하가 아니라 벽에 부딪히며 좌우로 꺾여 내려가는 맵
  — 🐍 지그재그 협곡(슬라럼 벽·삼각 섬·빗금 밭·지그재그 바) · 🌪 깔때기 폭포(구멍 위치가 번갈아 바뀌는 병목 연속).
  `wallPath` 헬퍼가 꺾은선 경로를 벽 조각들로 변환합니다.
  혹시 오목한 곳에 공이 걸려도 **갇힘 구출**(게임 시간 5초간 하강 진전이 없으면 자동으로 튕겨줌)이 살려냅니다.
- **🗺 맵 갤러리**: 홈 화면에서 진입. 평점 높은 순으로 모든 맵을 훑어보고, **👁 구경**으로 맵 전체를 읽기 전용 뷰어에서 미리 볼 수 있으며(회전체는 실제로 돌아감), 💬 후기도 여기서 읽고 씁니다.
- **유저 맵**: 갤러리의 **🛠 새 맵 만들기**로 누구나 제작 가능. 저장하면 서버의 모든 방에서 선택할 수 있고, `data/maps.json`에 영구 저장되어 서버를 재시작해도 유지됩니다.
- 맵 에디터: 팔레트에서 구성요소 선택 → 보드 클릭으로 배치 → 드래그로 이동 → 슬라이더로 속성(길이·각도·회전 속도 등) 조절. 회전체는 에디터에서도 실제 속도로 돌아가는 미리보기를 보여줍니다.
- **맵 길이도 에디터에서 조절**: 📐 맵 길이 슬라이더(900~12000, 기본 4800)로 짧은 스프린트 맵부터 초장거리 맵까지 만들 수 있습니다. 골인선·미니맵 비율·배치 가능 영역이 길이에 맞춰 자동 조정됩니다.
- 맵이 길기 때문에 에디터에서는 **휠 스크롤 / 방향키 / 미니맵 클릭**으로 이동하며 배치합니다.

### 새 구성요소 추가하기

`public/components.js` 의 `COMPONENTS` 객체에 항목 하나만 추가하면 됩니다.
**서버 물리 바디 생성, 클라이언트 렌더링, 에디터 팔레트/속성 슬라이더가 모두 자동 반영**되므로 다른 코드는 수정할 필요가 없습니다.

```js
// public/components.js
windmill: {
  id: 'windmill',
  name: '풍차',
  emoji: '🌬️',
  desc: '날개 3개로 돌아가는 풍차',
  props: [
    { key: 'length', label: '날개 길이', min: 60, max: 200, step: 10, default: 120 },
    { key: 'speed',  label: '회전 속도', min: -4, max: 4, step: 0.5, default: 1 },
  ],
  build(p) {
    const wing = (deg) => ({ kind: 'rect', x: 0, y: 0, w: p.length, h: 10, angle: deg * Math.PI / 180, fill: '#f0b458' });
    return {
      shapes: [wing(0), wing(60), wing(120), { kind: 'circle', x: 0, y: 0, r: 8, fill: '#ffd9a0' }],
      spin: p.speed,        // rad/s — 0이 아니면 배치 지점을 축으로 회전
      restitution: 0.8,     // 공이 튕기는 정도
    };
  },
},
```

- `shapes` — 배치 지점(0,0) 기준의 상대 도형 목록. 서버는 이를 그대로 물리 바디로, 클라이언트는 그대로 캔버스에 그립니다
- `spin` — 0이 아니면 회전체가 되어 서버 물리와 클라이언트 화면이 경과 시간 기준으로 결정적으로 동기화됩니다
- `props` — 에디터에 슬라이더로 자동 노출되고, 서버 저장 시 min/max로 잘려 검증됩니다
- `hit` — (선택) 공이 닿으면 발동하는 **반응형 동작** 데이터. 폭탄이 사용하는 방식으로, `{ action: 'explode', radius, power, respawnMs }` 처럼 선언하면 `server/game.js`의 `HIT_ACTIONS[action]` 이 실행합니다. 새 반응형 동작(닿으면 순간이동, 속도 감소 등)은 `HIT_ACTIONS`에 함수 하나를 추가하면 됩니다

### 2단계: 외부에서 접속 가능하게 (셋 중 택1)

| 방법 | 비용 | 장점 | 단점 |
|------|------|------|------|
| **A. 공유기 포트포워딩 + DDNS** | 무료 | 무제한 트래픽, 중간 서버 없음 | 집 IP 노출, HTTP(초대링크 복사는 수동 fallback) |
| **B. Cloudflare Tunnel** | 무료 (도메인 필요, 연 1~2만원) | HTTPS 자동, 집 IP 숨김, 포트포워딩 불필요 | 도메인 구매 필요 |
| **C. ngrok / Tailscale Funnel** | 무료 | 5분 설정, HTTPS, 도메인 불필요 | 무료 티어 제한(ngrok 경고 페이지, 대역폭) |

**A. 포트포워딩 + DDNS (ipTIME 기준)**
1. 공유기 관리자([192.168.0.1](http://192.168.0.1)) → 고급 설정 → NAT/라우터 관리 → **포트포워드**: 외부 포트 3000 → 내 PC IP의 3000
2. 특수기능 → **DDNS 설정**: `내아이디.iptime.org` 등록 (유동 IP 대응)
3. Windows 방화벽 → 인바운드 규칙 → 포트 3000 허용
4. 친구에게 `http://내아이디.iptime.org:3000` 공유

**B. Cloudflare Tunnel + 도메인 (가장 전문적, 추천)**

집 PC에 도메인을 붙이는 가장 깔끔한 방법입니다. 포트포워딩 없이 HTTPS 주소가 생기고, 집 IP가 노출되지 않으며, 유동 IP 문제도 자동 해결됩니다.

1. **도메인 구매** (연 1~2만원): Cloudflare Registrar(원가 판매), 가비아, Namecheap 등
2. **Cloudflare 무료 플랜에 도메인 등록**: dash.cloudflare.com → 사이트 추가 → 안내대로 네임서버 변경
3. **cloudflared 설치** (Windows: `winget install Cloudflare.cloudflared`, macOS: `brew install cloudflared`)
4. **터널 생성 및 연결**:
   ```bash
   cloudflared tunnel login                                # 브라우저에서 도메인 승인
   cloudflared tunnel create pinball
   cloudflared tunnel route dns pinball game.내도메인.com
   cloudflared tunnel run --url http://localhost:3000 pinball
   ```
5. → `https://game.내도메인.com` 접속 완료. WebSocket(Socket.IO)도 무료 지원.
6. **부팅 시 자동 실행** (Windows): `%USERPROFILE%\.cloudflared\config.yml` 파일을 만들고
   ```yaml
   tunnel: pinball
   credentials-file: C:\Users\내계정\.cloudflared\<터널UUID>.json
   ingress:
     - hostname: game.내도메인.com
       service: http://localhost:3000
     - service: http_status:404
   ```
   관리자 PowerShell에서 `cloudflared service install` → Windows 서비스로 등록되어 부팅 시 자동 연결됩니다

**도메인 없이 A안(포트포워딩)에 도메인만 붙이려면**: DNS A 레코드를 집 IP로 지정하고, 유동 IP 갱신은 공유기 DDNS 또는 Cloudflare API 갱신 스크립트를 사용합니다. 단, `http://도메인:3000` 형태가 되고 IP가 노출되므로 B안을 추천합니다.

**C. ngrok (가장 빠른 시작)**
```bash
# ngrok.com 가입 → 무료 고정 도메인 1개 발급
ngrok http 3000 --domain=발급받은이름.ngrok-free.app
```

### 후원자 명예의 전당 & 혜택

후원을 받으면 관리자가 후원자를 등록하고 **후원자 코드**를 발급받아 전달합니다.

- 후원자 목록은 `data/donors.json`에 저장되며 직접 편집해도 됩니다.

시상대(그 판의 결과)와 별개로, **모든 게임의 결과가 닉네임 기준으로 누적**되는 전체 순위가 있습니다.
홈 화면과 게임 결과 화면의 "📊 전체 순위" 버튼으로 볼 수 있습니다.

- 점수 = 참가자 수 − 순위 + 1 (예: 4인 게임 1등 4점, 꼴찌 1점 — 다인 게임 우승일수록 높은 점수)
- 승수·판수도 함께 표시, 점수순 정렬
- 혼자 플레이한 게임은 집계되지 않습니다 (승수 뻥튀기 방지)
- `data/stats.json`에 저장되어 서버를 재시작해도 유지됩니다

## 게임 규칙 커스터마이징

`server/game.js` 상단 상수:

- `TIME_SCALE` — **낙하 배속(공의 속도)**, `server/config.js` 설정 파일에서 조절 (기본 5). 환경변수 `TIME_SCALE=3 npm start` 또는 `scripts\start.bat`의 `set TIME_SCALE=` 로도 지정할 수 있습니다. 낙하가 시작되면 물리 시뮬레이션을 틱당 이 배수만큼 돌려 공이 그만큼 빠르게 떨어집니다. 셔플 단계는 항상 실시간(1배속)이고, 아이템 지속시간·폭탄 재생성 등 게임 내 타이머는 게임 시간 기준이라 배속을 바꿔도 밸런스가 유지됩니다
- `ITEM_INTRO_MS` — **아이템 소개 시간**, `server/config.js` 설정 파일에서 조절 (기본 6000ms). 게임 시작 직후 각자 받은 아이템을 카드로 보여주는 시간으로, 이 동안 셔플·낙하가 잠깁니다. `0`으로 두면 소개 없이 바로 셔플이 시작되고, 환경변수 `ITEM_INTRO_MS=0 npm start` 로도 지정할 수 있습니다 (올랜덤 모드는 항상 건너뜀)
- `ITEMS_PER_PLAYER` — 인당 아이템 개수 (기본 2)
- `GAME_TIMEOUT_MS` — 제한시간(게임 시간 기준), 초과 시 현재 위치 순으로 순위 결정
- `MAX_PLAYERS` — `server/rooms.js`, 방 최대 인원 (기본 10, 관전자는 무제한)
- `WORLD` — `public/components.js`, 보드 폭·기본 길이·길이 허용 범위(minHeight~maxHeight). 맵별 길이는 에디터에서 조절하며, 서버 물리·클라이언트 렌더링·미니맵이 모두 맵의 길이를 따릅니다
