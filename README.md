# 🎱 핀볼 공뽑기 (Dopamine Pinball)

친구를 초대해서 함께 즐기는 **멀티플레이어 물리엔진 뽑기 레이스** 게임입니다.
각자 공 하나를 배정받고, 세로로 긴 핀볼 보드(600×2400)를 따라 공이 떨어지며 먼저 골인하는 순서로 순위가 정해집니다.
화면은 내 공을 따라 내려가고, **우측 상단 미니맵**으로 전체 맵과 모든 공의 위치를 한눈에 볼 수 있습니다.
게임 시작 시 **랜덤 아이템 2개**를 받아 상대를 방해하거나 내 공을 가속할 수 있습니다.

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

1. 닉네임 입력, **우승 조건 선택**(🥇 먼저 골인 / 🐢 늦게 골인) 후 **방 만들기**
2. **초대 링크 복사** 버튼으로 친구에게 링크 전달 (또는 6자리 초대 코드 공유)
3. 방장이 **맵 선택** (기본 맵 또는 유저 제작 맵) — 누구나 **🛠 맵 만들기**로 직접 맵을 만들어 공유할 수 있어요. 우승 조건도 대기실에서 변경 가능
4. 친구가 모이면 방장이 **게임 시작**
5. 3초 카운트다운 후 공이 떨어집니다. 아이템을 써서 우승하세요!

### 우승 조건

- **🥇 먼저 골인 우승** (기본): 먼저 도착한 순서대로 순위. 미도착 공은 골인 지점에 가까운 순
- **🐢 늦게 골인 우승**: 늦게 도착할수록 높은 순위. 아이템의 의미가 뒤집힙니다 — 상대를 얼리면 오히려 도와주는 셈이고, 로켓 부스트는 자폭이 됩니다!

## 아키텍처

| 구성 | 선택 | 이유 |
|------|------|------|
| 물리엔진 | [Matter.js](https://brm.io/matter-js/) | 웹 물리엔진 중 가장 가볍고(min+gzip ≈ 80KB) 서버/브라우저 양쪽에서 동작 |
| 실시간 통신 | Socket.IO | 방(room) 개념 내장, 재연결 처리 자동 |
| 동기화 | **서버 권위(server-authoritative)** | 물리 시뮬레이션은 서버에서만 실행(60Hz), 클라이언트는 좌표 스냅샷(30Hz)을 받아 보간 렌더링만 수행 |

서버 권위 방식을 쓰는 이유:
- 참가자 전원이 **완전히 동일한 결과**를 봅니다 (물리엔진은 기기마다 미세하게 달라질 수 있음 → 뽑기 게임에서 치명적)
- 클라이언트는 물리 연산을 하지 않아 **저사양 기기/모바일에서도 가볍게** 동작
- 아이템 효과(상대 공 멈추기 등)를 서버에서 검증하므로 치팅 방지

```
server/
  index.js       # Express + Socket.IO 부트스트랩
  rooms.js       # 방 생성/초대코드 입장/방장 승계/맵 선택/퇴장 처리
  game.js        # Matter.js 시뮬레이션 루프, 맵 → 보드 생성, 순위 판정
  items.js       # ★ 아이템 레지스트리 (여기에 추가하면 끝)
  maps.js        # 기본 맵 + 유저 맵 저장소 (data/maps.json 영구 저장, 검증)
public/
  components.js  # ★ 맵 구성요소 레지스트리 (서버/클라이언트 공용, 여기에 추가하면 끝)
  index.html     # 홈 / 대기실 / 맵 에디터 / 게임 화면
  client.js      # 캔버스 렌더러(스냅샷 보간), 맵 에디터, 아이템 UI, 소켓 핸들러
  style.css
data/
  maps.json      # 유저 제작 맵 (자동 생성, git 미추적)
```

## 아이템 시스템

현재 아이템:

| 아이템 | 대상 | 효과 |
|--------|------|------|
| 👻 유령 낙하 | 나 | 3초간 핀과 다른 공을 무시하고 그대로 떨어짐 |
| 🧊 얼리기 | 상대 | 상대 공을 3초간 그 자리에 정지 |
| 🚀 로켓 부스트 | 나 | 공이 아래로 강하게 가속 |
| 🌪️ 돌풍 | 상대 | 상대 공을 위로 날려버림 |
| 💥 충격파 | 나 | 내 공 주변에 폭발을 일으켜 근처의 다른 공들을 날려버림 |
| 🎈 풍선 | 상대 | 상대 공이 3초간 커지고 잘 튕겨서 제어 불능 |

### 새 아이템 추가하기

`server/items.js` 의 `ITEMS` 객체에 항목 하나만 추가하면 됩니다.
이름/이모지/설명/대상 선택 UI까지 클라이언트에 자동 반영되므로 **클라이언트 코드 수정이 필요 없습니다.**

```js
// server/items.js
magnet: {
  id: 'magnet',
  name: '자석',
  emoji: '🧲',
  desc: '3초간 내 공이 골인 지점으로 끌려갑니다.',
  target: 'self',        // 'self' = 내 공 | 'opponent' = 대상 선택 UI 표시
  duration: 3000,        // 0이면 즉발형
  apply(game, ball) {
    ball.plugin.magnet = true;   // 지속 효과는 game.js tick에서 활용 가능
  },
  expire(game, ball) {
    ball.plugin.magnet = false;
  },
},
```

- `apply(game, ball)` — 효과 시작. `Matter.Body.setVelocity` 등으로 물리 상태를 조작하거나 `ball.plugin` 에 플래그 저장
- `expire(game, ball)` — `duration` 경과 후 자동 호출되어 효과 해제
- 배정 개수는 `server/game.js` 의 `ITEMS_PER_PLAYER` 상수로 조절

## 맵 시스템

- **기본 맵**: ⭐클래식(핀 격자), ⭐스피너 파크(회전 막대·회전 십자·범퍼)
- **유저 맵**: 대기실의 **🛠 맵 만들기**로 누구나 제작 가능. 저장하면 서버의 모든 방에서 선택할 수 있고, `data/maps.json`에 영구 저장되어 서버를 재시작해도 유지됩니다.
- 맵 에디터: 팔레트에서 구성요소 선택 → 보드 클릭으로 배치 → 드래그로 이동 → 슬라이더로 속성(길이·각도·회전 속도 등) 조절. 회전체는 에디터에서도 실제 속도로 돌아가는 미리보기를 보여줍니다.
- **맵 길이도 에디터에서 조절**: 📐 맵 길이 슬라이더(900~6000, 기본 2400)로 짧은 스프린트 맵부터 초장거리 맵까지 만들 수 있습니다. 골인선·미니맵 비율·배치 가능 영역이 길이에 맞춰 자동 조정됩니다.
- 맵이 길기 때문에 에디터에서는 **휠 스크롤 / 방향키 / 미니맵 클릭**으로 이동하며 배치합니다.
- 서버가 저장 시 좌표 범위·속성 범위·구성요소 개수(최대 150개)를 검증하므로 조작된 데이터는 저장되지 않습니다.

### 현재 구성요소

| 구성요소 | 속성 | 설명 |
|----------|------|------|
| 📍 핀 | 크기 | 공이 튕기는 기본 핀 |
| 🔴 범퍼 | 크기 | 닿으면 강하게 튕겨나감 (반발력 1.4) |
| 📏 벽 | 길이, 각도 | 기울일 수 있는 고정 벽 |
| 🌀 회전 막대 | 길이, 회전 속도 | 뱅글뱅글 돌며 공을 쳐내는 방해물 |
| ➕ 회전 십자 | 길이, 회전 속도 | 십자 모양 회전 방해물 |
| 💣 폭탄 | 폭발 범위, 폭발력, 재생성 시간 | 공이 닿으면 폭발 — 범위 안의 모든 공이 방사형으로 튕겨나감. 재생성 시간 후 다시 생김 (0이면 게임당 1회) |

### 새 구성요소 추가하기

`public/components.js` 의 `COMPONENTS` 객체에 항목 하나만 추가하면 됩니다.
**서버 물리 바디 생성, 클라이언트 렌더링, 에디터 팔레트/속성 슬라이더가 모두 자동 반영**되므로 다른 코드는 수정할 필요가 없습니다.

```js
// public/components.js
windmill: {
  id: 'windmill',
  name: '풍차',
  emoji: '🌬️',
  desc: '날개 3개로 돌아가는 풍차',
  props: [
    { key: 'length', label: '날개 길이', min: 60, max: 200, step: 10, default: 120 },
    { key: 'speed',  label: '회전 속도', min: -4, max: 4, step: 0.5, default: 1 },
  ],
  build(p) {
    const wing = (deg) => ({ kind: 'rect', x: 0, y: 0, w: p.length, h: 10, angle: deg * Math.PI / 180, fill: '#f0b458' });
    return {
      shapes: [wing(0), wing(60), wing(120), { kind: 'circle', x: 0, y: 0, r: 8, fill: '#ffd9a0' }],
      spin: p.speed,        // rad/s — 0이 아니면 배치 지점을 축으로 회전
      restitution: 0.8,     // 공이 튕기는 정도
    };
  },
},
```

- `shapes` — 배치 지점(0,0) 기준의 상대 도형 목록. 서버는 이를 그대로 물리 바디로, 클라이언트는 그대로 캔버스에 그립니다
- `spin` — 0이 아니면 회전체가 되어 서버 물리와 클라이언트 화면이 경과 시간 기준으로 결정적으로 동기화됩니다
- `props` — 에디터에 슬라이더로 자동 노출되고, 서버 저장 시 min/max로 잘려 검증됩니다
- `hit` — (선택) 공이 닿으면 발동하는 **반응형 동작** 데이터. 폭탄이 사용하는 방식으로, `{ action: 'explode', radius, power, respawnMs }` 처럼 선언하면 `server/game.js`의 `HIT_ACTIONS[action]` 이 실행합니다. 새 반응형 동작(닿으면 순간이동, 속도 감소 등)은 `HIT_ACTIONS`에 함수 하나를 추가하면 됩니다

## 후원 버튼 (서버 유지비)

환경변수에 후원 링크를 넣고 서버를 실행하면 홈·대기실·게임 결과 화면에 후원 버튼이 나타납니다.
링크가 없으면 버튼은 자동으로 숨겨집니다.

```bash
DONATION_URL=https://toss.me/내아이디 npm start

# 버튼 문구도 바꾸고 싶다면
DONATION_URL=https://toss.me/내아이디 DONATION_LABEL="💖 개발자 응원하기" npm start
```

후원 링크 만들기 (쉬운 순):

| 수단 | 대상 | 만드는 법 | 수수료 |
|------|------|-----------|--------|
| 토스아이디 | 한국 | 토스 앱 → 전체 → 토스아이디 만들기 → `toss.me/아이디` | 없음 |
| 카카오페이 송금링크 | 한국 | 카카오페이 → 송금 → 송금링크 만들기 | 없음 |
| Ko-fi | 글로벌 | ko-fi.com 가입 후 PayPal 연동 → `ko-fi.com/아이디` | 기본 0% |
| GitHub Sponsors | 개발자/오픈소스 | github.com/sponsors 등록 (한국 지원) | 0% |

### 후원자 명예의 전당 & 혜택

후원을 받으면 관리자가 후원자를 등록하고 **후원자 코드**를 발급받아 전달합니다.

```bash
# 서버 실행 시 관리자 키 설정
ADMIN_KEY=비밀키 DONATION_URL=https://toss.me/내아이디 npm start

# 후원자 등록 → 후원자 코드(DN-XXXXXX) 발급
curl -X POST http://localhost:3000/api/admin/donors \
  -H "x-admin-key: 비밀키" -H "Content-Type: application/json" \
  -d '{"name":"홍길동","amount":10000}'
# → {"ok":true,"code":"DN-ABC123","name":"홍길동"}
```

- **🏆 명예의 전당**: 홈 화면에서 누구나 후원자 목록(이름·금액, 금액순)을 볼 수 있습니다. 후원자 코드는 절대 공개되지 않습니다.
- **💖 후원자 혜택**: 후원자가 홈 화면에서 코드를 입력하면 (localStorage에 저장되어 한 번만 입력)
  - 대기실·게임 화면 이름에 💖 배지 표시
  - **에픽 아이템 확률 2배** (25% → 50%)
- 후원자 목록은 `data/donors.json`에 저장되며 직접 편집해도 됩니다.

| 등급 | 아이템 | 기본 확률 | 후원자 확률 |
|------|--------|-----------|-------------|
| ⭐ 에픽 | 👻 유령 낙하, 🧊 얼리기, 💥 충격파 | 25% | **50%** |

## 게임 규칙 커스터마이징

`server/game.js` 상단 상수:

- `ITEMS_PER_PLAYER` — 인당 아이템 개수 (기본 2)
- `COUNTDOWN_MS` — 시작 카운트다운 (기본 3초)
- `GAME_TIMEOUT_MS` — 제한시간, 초과 시 현재 위치 순으로 순위 결정 (기본 180초)
- `MAX_PLAYERS` — `server/rooms.js`, 방 최대 인원 (기본 8)
- `WORLD` — `public/components.js`, 보드 폭·기본 길이·길이 허용 범위(minHeight~maxHeight). 맵별 길이는 에디터에서 조절하며, 서버 물리·클라이언트 렌더링·미니맵이 모두 맵의 길이를 따릅니다
